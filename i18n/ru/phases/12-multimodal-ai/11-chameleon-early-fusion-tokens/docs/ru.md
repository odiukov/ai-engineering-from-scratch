# Chameleon и мультимодальные модели на одних токенах с ранней фузией

> Все VLM, которые мы видели до сих пор, держат картинки и текст порознь. Визуальные токены приходят из vision encoder, идут через проектор и только потом встречаются с текстом внутри LLM. Словари для картинок и для текста нигде не пересекаются. Chameleon (Meta, май 2024) спросил: а что если бы пересекались? Обучите VQ-VAE, который превращает картинку в последовательность дискретных токенов из общего словаря. Теперь любой мультимодальный документ — это одна последовательность: текстовые и картиночные токены вперемешку, один авторегрессионный лосс. Побочный эффект: модель умеет выдавать смешанные по модальности выходы — чередовать текст и картинки в рамках одного вызова инференса. В этом уроке мы разберём тезис ранней фузии и соберём игрушечную версию от начала до конца.

**Type:** Build
**Languages:** Python (stdlib, VQ-VAE tokenizer + interleaved decoder)
**Prerequisites:** Phase 12 · 05, Phase 8 (Generative AI)
**Time:** ~180 minutes

## Learning Objectives

- Объяснить, почему общий словарь плюс один лосс меняют сам набор возможностей модели.
- Описать, как VQ-VAE токенизирует картинку в дискретную последовательность, совместимую с задачей предсказания следующего токена.
- Назвать приёмы Chameleon для устойчивого обучения: QK-Norm, расстановка dropout, порядок LayerNorm.
- Сравнить Chameleon с подходом Q-Former из BLIP-2 и сказать, когда какой выбор правильный.

## The Problem

VLM на адаптерах (LLaVA, BLIP-2, Qwen-VL) считают текст и картинку двумя разными вещами. Текстовый токен проходит через `embed(text_token)`; картинка идёт через `visual_encoder(image) → projector → ... pseudo_tokens`. У модели два входных пути, которые сливаются где-то на середине.

Отсюда три следствия:

1. LLM умеет только потреблять картинки, но не выдавать их. На выходе только текст.
2. Документы со смешанными модальностями (абзацы и картинки вперемешку, как в статье) обрабатывать неудобно: либо вы разбираете мультимодальный вход вне модели, либо сцепляете несколько генераций.
3. Расхождение распределений. Визуальные и текстовые токены живут в разных областях скрытого пространства, и это порождает тонкие проблемы выравнивания.

> 🎒 **На пальцах.** Представьте переводчика, который понимает жесты, но сам показывать их не умеет — только говорит словами. Так работает LLaVA: картинку она прочитает, а нарисовать ответ не сможет, потому что в её словаре просто нет «картиночных» слов. Все три следствия выше растут из одного корня: два входа, один выход.

Chameleon отбрасывает саму посылку: картинки — это просто последовательности дискретных токенов из общего словаря. Обучите модель на перемешанных документах, один лосс, один авторегрессионный декодер — и генерация со смешанными модальностями достаётся вам бесплатно.

> 🎒 **На пальцах.** «Бесплатно» здесь не фигура речи. Вы не добавляете ни отдельную голову для картинок, ни второй лосс, ни диффузионный планировщик — модель просто предсказывает следующий токен, а какой он модальности, ей всё равно. Как если бы вы научили человека одному алфавиту, в котором есть и буквы, и мазки кисти.

## The Concept

### VQ-VAE as image tokenizer

Токенизатор — это векторно-квантованный вариационный автокодировщик. Устройство:

- Encoder: CNN + ViT, который превращает картинку в пространственную карту признаков, скажем 32x32 признака размерности 256.
- Codebook: обученный словарь из K векторов (Chameleon берёт 8192), тоже размерности 256.
- Quantization: для каждого пространственного признака ищем ближайшую запись codebook по L2-расстоянию. Непрерывный признак заменяем на целый индекс.
- Decoder: CNN, которая из квантованных признаков собирает пиксели обратно.

Обучение: лосс реконструкции VAE + commitment loss + codebook loss. Индексы codebook и образуют дискретный алфавит для картинок.

> 🎒 **На пальцах.** Codebook — это набор кистей: 8192 заранее выученных «мазка». Квантование смотрит на каждый из 32x32 = 1024 участков картинки и говорит: «здесь мазок номер 4821». Дальше картинка живёт как список из 1024 чисел от 0 до 8191, и никаких дробных значений там больше нет.

Для Chameleon: одна картинка становится 32*32 = 1024 токена из словаря на 8192. Сцепляем их с текстовыми токенами (из BPE-словаря самой LLM, скажем 32000). Итоговый словарь: 40192. Трансформер видит одну последовательность и один лосс.

> 🎒 **На пальцах.** Сложите словари: 32000 + 8192 = 40192, и всё это один диапазон ID. Токен 17 — какое-то слово, токен 35000 — какой-то мазок кисти, а softmax на выходе выбирает между ними как между равноправными вариантами. Именно поэтому модель физически способна «сказать» картинку.

### The shared vocabulary

Словарь Chameleon объединяет текстовые токены, картиночные токены и разделители модальностей. У каждого токена один ID. Входной слой эмбеддингов отображает любой ID в скрытый вектор размерности D. Выходная проекция превращает скрытое состояние обратно в логиты по словарю. Softmax выбирает следующий токен — какой угодно модальности.

Разделители важны: теги `<image>` и `</image>` обрамляют последовательность картиночных токенов. На генерации, если модель выдала `<image>`, окружающий софт знает: следующие 1024 токена — это VQ-индексы, которые надо отправить в декодер для отрисовки пикселей.

> 🎒 **На пальцах.** Теги работают как кавычки в тексте: сами по себе ничего не значат, но говорят читателю, как понимать то, что внутри. Без `</image>` софт не поймёт, где картинка кончилась и начался обычный текст, и попробует нарисовать ваше описание кошки как пиксели.

### Mixed-modality generation

Инференс — это предсказание следующего токена в общем словаре. Пример промпта: «Нарисуй кота и опиши его». Chameleon выдаёт:

```
<image> 4821 1029 2891 ... (1024 image tokens) </image>
The cat is orange, sitting on a windowsill...
```

Порядок модель выбирает сама: может выдать сперва картинку, потом текст, может наоборот, а может перемешать. Тот же декодер, тот же лосс.

Сравните с VLM на адаптерах, где генерация только текстовая. Chameleon заново открывает вопрос о том, в каких модальностях модель вообще может отвечать.

> 🎒 **На пальцах.** Обратите внимание: в выводе выше 1024 числа между тегами — это и есть картинка, просто записанная как текст. Модель не «переключалась в режим рисования», она сделала 1024 обычных шага предсказания следующего токена, а потом ещё десяток шагов на подпись «The cat is orange».

### Training stability — QK-Norm, dropout, LayerNorm ordering

Обучение с ранней фузией на большом масштабе нестабильно. Статья Chameleon описывает три приёма:

- QK-Norm. Применяем LayerNorm к проекциям query и key внутри внимания, до скалярного произведения. Не даёт величине логитов взрываться с глубиной. Этим пользуются несколько крупных моделей после 2024 года.
- Dropout placement. Dropout после каждого сложения с residual, а не только после внимания и MLP. Регуляризации нужно больше, потому что градиенты от картиночных токенов могут перебивать остальные.
- LayerNorm ordering. Pre-LN на residual-ветке (как обычно) плюс дополнительный LN на skip-соединении последнего блока. Стабилизирует поток градиента в финальном слое.

> 🎒 **На пальцах.** QK-Norm легко понять на числах: если у query и key норма выросла с 1 до 10, их скалярное произведение вырастет в 100 раз, а softmax после этого станет почти one-hot — градиенты умрут. LayerNorm просто возвращает обоим векторам единичный масштаб перед умножением, и внимание остаётся «мягким».

Без этих приёмов обучение Chameleon на 34B параметров расходилось на нескольких чекпойнтах. С ними — сходится. Рецепт обучения тут вносит в результат не меньше, чем сама архитектура.

> 🎒 **На пальцах.** «Расходилось на нескольких чекпойнтах» означает буквально: люди неделями жгли тысячи GPU, лосс улетал в NaN, они откатывались назад и пробовали снова. Три строчки кода про нормализацию сэкономили здесь месяцы вычислений — поэтому статью про Chameleon читают ради раздела 2.3, а не ради картинки архитектуры.

### The tokenizer's reconstruction ceiling

VQ-VAE теряет информацию. При 8192 записях в codebook и 1024 токенах на картинку 512x512 PSNR реконструкции упирается в 26-28 dB. Этого хватает на узнаваемую генерацию картинок, но заметно хуже, чем у диффузии в непрерывном пространстве (Stable Diffusion 3 даёт 32+ dB).

> 🎒 **На пальцах.** Посчитаем сжатие: 1024 токена по 13 бит (потому что 2^13 = 8192) — это 13312 бит, около 1.6 КБ. Оригинал 512x512 в 24-битном RGB — 786 КБ. Сжатие почти в 500 раз, и вот эти потерянные 499/500 и есть разница между 27 и 32 dB.

Токенизатор — это узкое место. Токенизаторы получше (MAGVIT-v2, IBQ, SBER-MoVQGAN) поднимают потолок. Emu3 (урок 12.12) добивается качества уровня SDXL одним только улучшением токенизатора.

> 🎒 **На пальцах.** Здесь важная мысль: потолок ставит не трансформер, а токенизатор. Как бы идеально модель ни предсказывала индексы, лучше 27 dB картинка не станет — декодер физически не умеет больше. Хотите качества выше — меняйте не размер модели, а codebook.

### Chameleon vs BLIP-2 / LLaVA

Chameleon (ранняя фузия, общий словарь):
- Один лосс, один декодер.
- Выдаёт выход со смешанными модальностями.
- Потолок качества задаёт токенизатор.
- Дорого: на инференсе на каждую сгенерированную картинку нужен проход VQ-VAE-декодера.

BLIP-2 / LLaVA (поздняя фузия, отдельные башни):
- Картинка на входе, только текст на выходе.
- Переиспользует предобученную LLM.
- Для понимания картинок узкого места в виде токенизатора нет.
- Дёшево: один forward pass.

Выбирайте по задаче. Нужна генерация картинок — семейство Chameleon. Нужно только понимание — VLM на адаптерах проще и переиспользует больше уже потраченных вычислений.

> 🎒 **На пальцах.** Правило простое: считайте, сколько путей у сигнала. У LLaVA один проход и текст на выходе — идеально для «опиши, что на фото». У Chameleon после генерации ещё запускается декодер VQ-VAE, чтобы 1024 индекса превратить в пиксели, — лишняя работа, которая нужна только если вы правда хотите картинку.

### Fuyu and AnyGPT

Fuyu (Adept, 2023) — родственный подход: вообще отказаться от отдельного vision encoder, кормить сырые патчи картинки в входную проекцию LLM как если бы они были токенами, без токенизатора. Проще, чем Chameleon, но теряется генерация выходов через общий словарь.

AnyGPT (Zhan и соавторы, 2024) расширяет Chameleon на четыре модальности: текст, картинка, речь, музыка. Тот же трюк с VQ-VAE для каждой, общий трансформер. Генерация из любого в любое. Подробнее в уроке 12.16.

> 🎒 **На пальцах.** Разница между Fuyu и Chameleon — в дискретности. Fuyu подаёт патчи как непрерывные векторы, поэтому предсказать их softmax'ом нельзя: генерировать картинки не получится. Chameleon сначала округляет каждый патч до одного из 8192 кодов — и именно эта потеря точности открывает возможность выдавать картинки на выходе.

## Use It

`code/main.py` собирает игрушечную модель с ранней фузией целиком:

- Крошечный квантователь в духе VQ-VAE, который отображает патчи 8x8 в индексы codebook (K=16).
- Общий словарь: (текстовые id 0..31) + (картиночные id 32..47) + (разделители 48, 49).
- Игрушечный авторегрессионный декодер (таблица биграмм), обученный на синтетических подписях и последовательностях картиночных токенов.
- Цикл сэмплирования, который по промпту выдаёт чередующиеся текстовые и картиночные токены.

Трансформер здесь намеренно сделан крошечным (биграммы), чтобы можно было проследить путь сигнала от начала до конца.

> 🎒 **На пальцах.** Заметьте масштаб игрушки: словарь всего 50 токенов вместо 40192, а codebook на 16 кодов вместо 8192. Зато таблицу биграмм 50x50 можно распечатать на одном листе и глазами увидеть, что после id 48 (`<image>`) модель почти всегда выбирает id из диапазона 32..47.

## Key Terms

| Term | What people say | What it actually means |
|------|-----------------|------------------------|
| Early fusion | «Единые токены» | Картинки с самого начала переведены в дискретные токены, живущие в общем словаре трансформера |
| VQ-VAE | «Токенизатор картинок» | CNN + ViT + codebook, отображающие картинки в целые индексы, которые трансформер может предсказывать |
| Shared vocabulary | «Один словарь» | Единое пространство ID токенов, покрывающее текст, картинки и разделители модальностей |
| QK-Norm | «Стабилизатор внимания» | LayerNorm на query и key до их скалярного произведения; не даёт нормам взрываться |
| Mixed-modality generation | «Выход из текста и картинок» | Инференс, который сам выдаёт перемешанные текстовые и картиночные токены за один проход |
| Codebook size | «K записей» | Сколько дискретных векторов есть у VQ-VAE для квантования; размен сжатия на точность |
| Tokenizer ceiling | «Предел реконструкции» | Лучший PSNR, достижимый декодированием VQ-токенов; он ограничивает качество картинок модели |
