# Вероятность и распределения

> Вероятность — язык, на котором AI выражает неуверенность.

**Type:** Learn
**Language:** Python
**Prerequisites:** Phase 1, Lessons 01-04
**Time:** ~75 minutes

## Learning Objectives

- Реализовать с нуля PMF и PDF для распределений Бернулли, категориального, Пуассона, равномерного и нормального
- Вычислять математическое ожидание и дисперсию, объяснять через центральную предельную теорему, почему всюду гауссианы
- Построить функции softmax и log-softmax с приёмом численной устойчивости (вычитание максимального логита)
- Считать cross-entropy loss из логитов и связывать её с отрицательным логарифмом правдоподобия

> 🎒 **На пальцах.** Модель никогда не говорит «это кошка». Она говорит «кошка на 91%, собака на 6%, птица на 3%». Весь урок — про то, откуда берутся эти проценты и как их складывать без ошибок.

## The Problem

Классификатор выдаёт `[0.03, 0.91, 0.06]`. Языковая модель выбирает следующее слово из 50 000 кандидатов. Диффузионная модель порождает изображения, сэмплируя из выученных распределений. Всё это — вероятность в действии.

Каждое предсказание модели — распределение вероятностей. Каждая функция потерь измеряет, насколько предсказанное распределение далеко от истинного. Каждый шаг обучения подкручивает параметры, чтобы одно распределение стало похоже на другое. Без вероятности вы не прочитаете ни одной ML-статьи, не отладите ни одной модели и не поймёте, почему ваш training loss превратился в NaN.

> 🎒 **На пальцах.** Прогноз погоды не обещает дождь — он говорит «вероятность 70%». Честнее и полезнее, чем твёрдое «да» или «нет». Модели работают ровно так же.

## The Concept

### Events, Sample Spaces, and Probability

Пространство элементарных исходов S — множество всех возможных результатов. Событие — подмножество этого пространства. Вероятность сопоставляет событиям числа от 0 до 1.

```
Coin flip:
  S = {H, T}
  P(H) = 0.5,  P(T) = 0.5

Single die roll:
  S = {1, 2, 3, 4, 5, 6}
  P(even) = P({2, 4, 6}) = 3/6 = 0.5
```

Три аксиомы определяют всю теорию вероятностей:
1. P(A) >= 0 для любого события A
2. P(S) = 1 (что-нибудь обязательно случится)
3. P(A или B) = P(A) + P(B), когда A и B не могут произойти одновременно

Всё остальное (теорема Байеса, математические ожидания, распределения) выводится из этих трёх правил.

> 🎒 **На пальцах.** Правила придуманы не математиками из вредности, а из здравого смысла. «Вероятность не бывает отрицательной» — нельзя выпасть орлу минус три раза. «Всё вместе даёт 1» — что-то же выпадет. Всё, аксиомы кончились.

### Conditional Probability and Independence

P(A|B) — вероятность A при условии, что B произошло.

```
P(A|B) = P(A and B) / P(B)

Example: deck of cards
  P(King | Face card) = P(King and Face card) / P(Face card)
                      = (4/52) / (12/52)
                      = 4/12 = 1/3
```

Два события независимы, когда знание одного ничего не говорит о другом:

```
Independent:   P(A|B) = P(A)
Equivalent to: P(A and B) = P(A) * P(B)
```

Броски монеты независимы. Вытягивание карт без возврата — нет.

> 🎒 **На пальцах.** Условная вероятность — это «сузить круг подозреваемых». В колоде 52 карты, королей 4, шанс вытянуть короля 4/52 ≈ 8%. Но если вам сказали «это картинка» (валет, дама или король — их 12), круг сузился: теперь шанс 4 из 12, то есть 33%. Новая информация меняет ответ, хотя карта та же самая.

### Probability Mass Functions vs Probability Density Functions

У дискретных случайных величин есть функция вероятности (PMF). У каждого исхода конкретная вероятность, которую можно прочитать напрямую.

```
PMF: P(X = k)

Fair die:
  P(X = 1) = 1/6
  P(X = 2) = 1/6
  ...
  P(X = 6) = 1/6

  Sum of all probabilities = 1
```

У непрерывных случайных величин есть функция плотности (PDF). Плотность в одной точке — не вероятность. Вероятность получается интегрированием плотности по промежутку.

```
PDF: f(x)

P(a <= X <= b) = integral of f(x) from a to b

f(x) can be greater than 1 (density, not probability)
integral from -inf to +inf of f(x) dx = 1
```

Это различие важно в ML. Выходы классификации — PMF (дискретный выбор). Латентные пространства VAE используют PDF (непрерывные).

> 🎒 **На пальцах.** Дискретное — «какая цифра выпала на кубике»: 1, 2, 3... промежуточных нет. Непрерывное — «сколько ты весишь»: 45.3 кг, 45.31, 45.312... Вопрос «какова вероятность весить ровно 45 кг» бессмысленный, ответ ноль — надо спрашивать «от 44 до 46». Поэтому у непрерывных величин площадь, а не столбик.

### Common Distributions

**Bernoulli:** одно испытание, два исхода. Моделирует бинарную классификацию.

```
P(X = 1) = p
P(X = 0) = 1 - p
Mean = p,  Variance = p(1-p)
```

**Categorical:** одно испытание, k исходов. Моделирует многоклассовую классификацию (выход softmax).

```
P(X = i) = p_i,  where sum of p_i = 1
Example: P(cat) = 0.7,  P(dog) = 0.2,  P(bird) = 0.1
```

**Uniform:** все исходы равновероятны. Используется для случайной инициализации.

```
Discrete: P(X = k) = 1/n for k in {1, ..., n}
Continuous: f(x) = 1/(b-a) for x in [a, b]
```

**Normal (Gaussian):** колокол. Задаётся средним (mu) и дисперсией (sigma^2).

```
f(x) = (1 / sqrt(2*pi*sigma^2)) * exp(-(x - mu)^2 / (2*sigma^2))

Standard normal: mu = 0, sigma = 1
  68% of data within 1 sigma
  95% within 2 sigma
  99.7% within 3 sigma
```

**Poisson:** количество редких событий за фиксированный промежуток. Моделирует частоту событий.

```
P(X = k) = (lambda^k * e^(-lambda)) / k!
Mean = lambda,  Variance = lambda
```

> 🎒 **На пальцах.** По одному примеру на каждое: Бернулли — «пойдёт дождь или нет». Категориальное — «какой из трёх автобусов приедет первым». Равномерное — «какое число загадал компьютер от 1 до 100». Нормальное — «рост учеников в классе»: большинство около среднего, гигантов и коротышек мало. Пуассона — «сколько человек зайдёт в магазин за час».

### Expected Value and Variance

Математическое ожидание — средневзвешенный исход.

```
Discrete:   E[X] = sum of x_i * P(X = x_i)
Continuous: E[X] = integral of x * f(x) dx
```

Дисперсия измеряет разброс вокруг среднего.

```
Var(X) = E[(X - E[X])^2] = E[X^2] - (E[X])^2
Standard deviation = sqrt(Var(X))
```

В ML математическое ожидание появляется как функция потерь (средние потери по распределению данных). Дисперсия говорит об устойчивости модели. Высокая дисперсия градиентов означает шумное обучение.

> 🎒 **На пальцах.** Кубик: ожидание = (1+2+3+4+5+6)/6 = 3.5. Обратите внимание — 3.5 на кубике не выпадает никогда. Ожидание не обязано быть возможным исходом, это «в среднем за много бросков». А дисперсия отвечает на другой вопрос: разброс. У двух классов может быть одинаковый средний балл 4, но в одном все четвёрки, а в другом половина пятёрок и половина троек — вот это и есть разная дисперсия.

### Joint and Marginal Distributions

Совместное распределение P(X, Y) описывает две случайные величины вместе.

Пример совместной PMF (X = погода, Y = зонт):

| | Y=0 (no umbrella) | Y=1 (umbrella) | Marginal P(X) |
|---|---|---|---|
| X=0 (солнце) | 0.40 | 0.10 | P(X=0) = 0.50 |
| X=1 (дождь) | 0.05 | 0.45 | P(X=1) = 0.50 |
| **Marginal P(Y)** | P(Y=0) = 0.45 | P(Y=1) = 0.55 | 1.00 |

Маргинальное распределение «суммирует» вторую переменную:

```
P(X = x) = sum over all y of P(X = x, Y = y)
```

Итоги по строкам и столбцам в таблице выше и есть маргинальные распределения.

> 🎒 **На пальцах.** Это обычная таблица классного журнала. В клетках — сколько человек попало в каждое сочетание, справа и снизу — итоги. «Маргинальное» звучит страшно, а означает буквально «то, что написано на полях» — итоговый столбец. Из таблицы видно и другое: в дождь зонт берут в 45 случаях из 50, а на солнце в 10 из 50. Значит погода и зонт зависимы — что логично.

### Why the Normal Distribution Shows Up Everywhere

Центральная предельная теорема: сумма (или среднее) многих независимых случайных величин сходится к нормальному распределению независимо от исходного распределения.

```
Roll 1 die:  uniform distribution (flat)
Average of 2 dice:  triangular (peaked)
Average of 30 dice: nearly perfect bell curve

This works for ANY starting distribution.
```

Вот почему:
- Ошибки измерений приблизительно нормальны (много мелких независимых источников)
- Инициализация весов нейросетей использует нормальные распределения
- Шум градиентов в SGD приблизительно нормален (сумма многих градиентов по примерам)
- Нормальное распределение — распределение максимальной энтропии при заданных среднем и дисперсии

> 🎒 **На пальцах.** Один кубик: все шесть значений равновероятны, график плоский. Два кубика: сумма 7 выпадает чаще всего (шесть способов её получить), а 2 и 12 — только одним способом каждая. График стал горкой. Тридцать кубиков — почти идеальный колокол. Ничего не менялось, кроме количества слагаемых. Это самое удивительное правило в теории вероятностей.

### Log Probabilities

Сырые вероятности вызывают численные проблемы. Перемножение множества маленьких вероятностей быстро проваливается в ноль.

```
P(sentence) = P(word1) * P(word2) * ... * P(word_n)
            = 0.01 * 0.003 * 0.02 * ...
            -> 0.0 (underflow after ~30 terms)
```

Логарифмы вероятностей это чинят. Умножения превращаются в сложения.

```
log P(sentence) = log P(word1) + log P(word2) + ... + log P(word_n)
                = -4.6 + -5.8 + -3.9 + ...
                -> finite number (no underflow)
```

Правила:
- log(a * b) = log(a) + log(b)
- логарифмы вероятностей всегда <= 0 (так как 0 < P <= 1)
- Чем отрицательнее, тем менее вероятно
- Cross-entropy loss — отрицательный логарифм вероятности правильного класса

> 🎒 **На пальцах.** Перемножьте 0.01 тридцать раз — получите единицу с шестьюдесятью нулями после запятой. Компьютер такое число не хранит, он округляет его до нуля, и всё ломается. А сложить тридцать раз −4.6 — получится −138, совершенно нормальное число. Тот же ответ, только записанный так, чтобы не сломать арифметику.

### Softmax as a Probability Distribution

Нейросети выдают сырые оценки (логиты). Softmax превращает их в корректное распределение вероятностей.

```
softmax(z_i) = exp(z_i) / sum(exp(z_j) for all j)

Properties:
  - All outputs are in (0, 1)
  - All outputs sum to 1
  - Preserves relative ordering of inputs
  - exp() amplifies differences between logits
```

Приём softmax: вычесть максимальный логит перед экспонированием, чтобы избежать переполнения.

```
z = [100, 101, 102]
exp(102) = overflow

z_shifted = z - max(z) = [-2, -1, 0]
exp(0) = 1  (safe)

Same result, no overflow.
```

Log-softmax объединяет softmax и логарифм ради численной устойчивости. PyTorch использует его внутри cross-entropy loss.

> 🎒 **На пальцах.** Softmax — как распределить 100% голосов между кандидатами. Кто набрал больше очков, тот получит больше процентов, но каждому достанется хоть чуть-чуть, и в сумме будет ровно 100%. А приём с вычитанием максимума — как перевести все оценки в «на сколько ниже лучшего»: порядок и разрывы те же, а числа маленькие и калькулятор не взрывается.

### Sampling

Сэмплирование — вытягивание случайных значений из распределения. В ML:
- Dropout случайно выбирает, какие нейроны занулить
- Аугментация данных сэмплирует случайные преобразования
- Языковые модели сэмплируют следующий токен из предсказанного распределения
- Диффузионные модели сэмплируют шум и постепенно его убирают

Сэмплирование из произвольных распределений требует техник вроде метода обратной функции, отбраковки или reparameterization trick (используется в VAE).

## Build It

### Step 1: Probability basics

```python
import math
import random

def factorial(n):
    result = 1
    for i in range(2, n + 1):
        result *= i
    return result

def combinations(n, k):
    return factorial(n) // (factorial(k) * factorial(n - k))

def conditional_probability(p_a_and_b, p_b):
    return p_a_and_b / p_b

p_king_given_face = conditional_probability(4/52, 12/52)
print(f"P(King | Face card) = {p_king_given_face:.4f}")
```

### Step 2: PMF and PDF from scratch

```python
def bernoulli_pmf(k, p):
    return p if k == 1 else (1 - p)

def categorical_pmf(k, probs):
    return probs[k]

def poisson_pmf(k, lam):
    return (lam ** k) * math.exp(-lam) / factorial(k)

def uniform_pdf(x, a, b):
    if a <= x <= b:
        return 1.0 / (b - a)
    return 0.0

def normal_pdf(x, mu, sigma):
    coeff = 1.0 / (sigma * math.sqrt(2 * math.pi))
    exponent = -0.5 * ((x - mu) / sigma) ** 2
    return coeff * math.exp(exponent)
```

### Step 3: Expected value and variance

```python
def expected_value(values, probabilities):
    return sum(v * p for v, p in zip(values, probabilities))

def variance(values, probabilities):
    mu = expected_value(values, probabilities)
    return sum(p * (v - mu) ** 2 for v, p in zip(values, probabilities))

die_values = [1, 2, 3, 4, 5, 6]
die_probs = [1/6] * 6
mu = expected_value(die_values, die_probs)
var = variance(die_values, die_probs)
print(f"Die: E[X] = {mu:.4f}, Var(X) = {var:.4f}, SD = {var**0.5:.4f}")
```

> 🎒 **На пальцах.** Программа напечатает E[X] = 3.5 — то самое число, которое вы уже посчитали в уме. Дисперсия выйдет 2.9167, а стандартное отклонение около 1.71. Читается так: «типичный бросок отклоняется от 3.5 примерно на 1.7».

### Step 4: Sampling from distributions

```python
def sample_bernoulli(p, n=1):
    return [1 if random.random() < p else 0 for _ in range(n)]

def sample_categorical(probs, n=1):
    cumulative = []
    total = 0
    for p in probs:
        total += p
        cumulative.append(total)
    samples = []
    for _ in range(n):
        r = random.random()
        for i, c in enumerate(cumulative):
            if r <= c:
                samples.append(i)
                break
    return samples

def sample_normal_box_muller(mu, sigma, n=1):
    samples = []
    for _ in range(n):
        u1 = random.random()
        u2 = random.random()
        z = math.sqrt(-2 * math.log(u1)) * math.cos(2 * math.pi * u2)
        samples.append(mu + sigma * z)
    return samples
```

> 🎒 **На пальцах.** `sample_categorical` — это рулетка с секторами разной ширины. Вероятности 0.7, 0.2, 0.1 превращаются в границы 0.7, 0.9, 1.0. Компьютер бросает случайное число от 0 до 1 и смотрит, в какой сектор оно попало. Выпало 0.85 — это второй сектор. Вот и весь «искусственный интеллект выбирает слово».

### Step 5: Softmax and log probabilities

```python
def softmax(logits):
    max_logit = max(logits)
    shifted = [z - max_logit for z in logits]
    exps = [math.exp(z) for z in shifted]
    total = sum(exps)
    return [e / total for e in exps]

def log_softmax(logits):
    max_logit = max(logits)
    shifted = [z - max_logit for z in logits]
    log_sum_exp = max_logit + math.log(sum(math.exp(z) for z in shifted))
    return [z - log_sum_exp for z in logits]

def cross_entropy_loss(logits, target_index):
    log_probs = log_softmax(logits)
    return -log_probs[target_index]
```

### Step 6: Central Limit Theorem demonstration

```python
def demonstrate_clt(dist_fn, n_samples, n_averages):
    averages = []
    for _ in range(n_averages):
        samples = [dist_fn() for _ in range(n_samples)]
        averages.append(sum(samples) / len(samples))
    return averages
```

## Use It

С NumPy и SciPy всё вышеперечисленное — однострочники:

```python
import numpy as np
from scipy import stats

normal = stats.norm(loc=0, scale=1)
samples = normal.rvs(size=10000)
print(f"Mean: {np.mean(samples):.4f}, Std: {np.std(samples):.4f}")
print(f"P(X < 1.96) = {normal.cdf(1.96):.4f}")

logits = np.array([2.0, 1.0, 0.1])
from scipy.special import softmax, log_softmax
probs = softmax(logits)
log_probs = log_softmax(logits)
print(f"Softmax: {probs}")
print(f"Log-softmax: {log_probs}")
```

Вы построили это с нуля. Теперь вы знаете, что делают вызовы библиотеки.

> 🎒 **На пальцах.** Строчка `normal.cdf(1.96)` напечатает 0.975. Отсюда и знаменитое «95%»: между −1.96 и +1.96 сигмы лежит 95% всех значений. Именно это число вы видите в новостях как «погрешность опроса ±3%».

> 🎒 **На пальцах.** К третьему заданию: правильный класс имеет логит 3.0 — самый большой из всех. Значит модель угадала, и потери должны получиться маленькими (меньше единицы). ## Key Terms

| Term | What people say | What it actually means |
|------|----------------|----------------------|
| Sample space | «Все возможности» | Множество S всех возможных исходов эксперимента |
| PMF | «Функция вероятности» | Функция, дающая точную вероятность каждого дискретного исхода; в сумме даёт 1 |
| PDF | «Кривая вероятности» | Функция плотности для непрерывных величин. Проинтегрируйте её по промежутку, чтобы получить вероятность |
| Conditional probability | «Вероятность при условии» | P(A\|B) = P(A и B) / P(B). Основа байесовского мышления и теоремы Байеса |
| Independence | «Не влияют друг на друга» | P(A и B) = P(A) * P(B). Знание одного события ничего не говорит о другом |
| Expected value | «Среднее» | Взвешенная по вероятностям сумма всех исходов. Функция потерь — это математическое ожидание |
| Variance | «Насколько разбросано» | Ожидаемое квадратичное отклонение от среднего. Высокая дисперсия = шумные, неустойчивые оценки |
| Normal distribution | «Колокол» | f(x) = (1/sqrt(2*pi*sigma^2)) * exp(-(x-mu)^2/(2*sigma^2)). Встречается повсюду благодаря ЦПТ |
| Central Limit Theorem | «Средние становятся нормальными» | Среднее многих независимых выборок сходится к нормальному распределению независимо от источника |
| Joint distribution | «Две переменные вместе» | P(X, Y) описывает вероятность каждого сочетания исходов X и Y |
| Marginal distribution | «Просуммировать другую переменную» | P(X) = sum_y P(X, Y). Восстанавливает распределение одной переменной из совместного |
| Log probability | «Логарифм вероятности» | log P(x). Превращает произведения в суммы, предотвращая численное исчезновение в длинных последовательностях |
| Softmax | «Превратить оценки в вероятности» | softmax(z_i) = exp(z_i) / sum(exp(z_j)). Отображает вещественные логиты в корректное распределение вероятностей |
| Cross-entropy | «Функция потерь» | -sum(p_true * log(p_predicted)). Измеряет, насколько различны два распределения. Меньше — лучше |
| Logits | «Сырые выходы модели» | Ненормализованные оценки до softmax. Названы по логистической функции |
| Sampling | «Вытягивание случайных значений» | Порождение значений согласно распределению вероятностей. Так модели генерируют выход |
