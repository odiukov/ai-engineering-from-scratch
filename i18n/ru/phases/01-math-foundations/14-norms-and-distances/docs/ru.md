# Нормы и расстояния

> Ваша функция расстояния определяет, что значит «похожи». Ошибётесь с выбором — сломается всё, что дальше.

**Type:** Build
**Language:** Python
**Prerequisites:** Phase 1, Lessons 01 (Linear Algebra Intuition), 02 (Vectors, Matrices & Operations)
**Time:** ~90 minutes

## Learning Objectives

- Реализовать с нуля L1, L2, косинусное, Махаланобиса, Жаккара и редакционное расстояния
- Подбирать подходящую метрику расстояния под задачу ML и объяснять, почему альтернативы не годятся
- Связать нормы L1 и L2 с регуляризацией LASSO и Ridge и их геометрическими областями ограничений
- Показать, как один и тот же набор данных даёт разных ближайших соседей при разных метриках

> 🎒 **На пальцах.** «Далеко ли от школы до дома?» — ответ зависит от того, идёте вы пешком по улицам, летите по прямой или едете на метро. Три разных числа для одной пары точек. Компьютеру тоже нужно сказать, каким способом мерить.

## The Problem

У вас два вектора. Может, это векторные представления слов. Может, профили пользователей. Может, массивы пикселей. Вам нужно знать: насколько они близки?

Ответ целиком зависит от выбранной функции расстояния. Две точки данных могут быть ближайшими соседями по одной метрике и далёкими по другой. Ваш KNN-классификатор, рекомендательный движок, векторная база, алгоритм кластеризации, функция потерь — все зависят от этого выбора. Ошибётесь, и модель будет оптимизировать не то.

Универсально лучшего расстояния не существует. L2 работает для пространственных данных. Косинусная близость царит в NLP. Жаккар работает с множествами. Редакционное расстояние — со строками. Махаланобис учитывает корреляции. Расстояние Вассерштейна перемещает вероятностную массу. Каждое кодирует своё предположение о том, что значит «похожи».

Этот урок строит все основные функции расстояния с нуля, показывает, когда каждая уместна, и демонстрирует, как одни и те же данные дают совершенно разных ближайших соседей в зависимости от метрики.

## The Concept

### Norms: measuring vector magnitude

Норма измеряет «размер» вектора. Любую функцию расстояния между двумя векторами можно записать как норму их разности: d(a, b) = ||a - b||. Значит понять нормы — значит понять расстояния.

### L1 Norm (Manhattan distance)

Норма L1 суммирует абсолютные значения всех компонент.

```
||x||_1 = |x_1| + |x_2| + ... + |x_n|
```

Её называют манхэттенским расстоянием, потому что она измеряет путь по городской сетке, где двигаться можно только вдоль осей. Никаких диагоналей.

```
Point A = (1, 1)
Point B = (4, 5)

L1 distance = |4-1| + |5-1| = 3 + 4 = 7

On a grid, you walk 3 blocks east and 4 blocks north.
```

Когда использовать L1:
- Многомерные разреженные данные (текстовые признаки, one-hot кодировки)
- Когда нужна устойчивость к выбросам (одна огромная разница не доминирует)
- Задачи отбора признаков (L1-регуляризация даёт разреженность)

Связь с L1-регуляризацией (Lasso): добавление ||w||_1 к функции потерь штрафует сумму модулей весов. Это загоняет мелкие веса ровно в ноль, автоматически отбирая признаки. Штраф L1 создаёт ромбовидные области ограничений в пространстве весов, а углы ромба лежат на осях, где часть весов равна нулю.

Связь с функциями потерь: средняя абсолютная ошибка (MAE) — это среднее L1-расстояние между предсказаниями и целями. Она штрафует все ошибки линейно, что делает её устойчивее к выбросам по сравнению с MSE.

> 🎒 **На пальцах.** Вы в центре города. По прямой до дома 5 кварталов, но домов насквозь не бывает — идёте 3 квартала на восток и 4 на север, итого 7. Такси считает по этим 7, а не по 5. Вот и вся разница между L1 и L2.

### L2 Norm (Euclidean distance)

Норма L2 — расстояние по прямой. Корень из суммы квадратов компонент.

```
||x||_2 = sqrt(x_1^2 + x_2^2 + ... + x_n^2)
```

Это то расстояние, которое проходят на геометрии. Пифагор в n измерениях.

```
Point A = (1, 1)
Point B = (4, 5)

L2 distance = sqrt((4-1)^2 + (5-1)^2) = sqrt(9 + 16) = sqrt(25) = 5.0

The straight line, cutting diagonally through the grid.
```

Когда использовать L2:
- Данные малой и средней размерности, непрерывные
- Когда масштабы признаков сопоставимы
- Физические расстояния (пространственные данные, показания датчиков)
- Похожесть изображений на уровне пикселей

Связь с L2-регуляризацией (Ridge): добавление ||w||_2^2 к функции потерь штрафует большие веса. В отличие от L1 она не загоняет веса в ноль, а пропорционально ужимает все к нулю. Штраф L2 создаёт круглые области ограничений, углов на осях нет. Веса становятся маленькими, но ровно нулевыми — редко.

Связь с функциями потерь: среднеквадратичная ошибка (MSE) — среднее квадратов L2-расстояний. Возведение в квадрат наказывает большие ошибки сильнее, чем мелкие.

```
MAE (L1 loss):  |y - y_hat|         Linear penalty. Robust to outliers.
MSE (L2 loss):  (y - y_hat)^2       Quadratic penalty. Sensitive to outliers.
```

> 🎒 **На пальцах.** Заметьте: 3 и 4 в примере дали ровно 5. Тот самый школьный треугольник 3-4-5. А разница метрик видна сразу: по улицам 7, по прямой 5. Ворона летит короче, чем едет машина.

### Lp Norms: the general family

L1 и L2 — частные случаи нормы Lp:

```
||x||_p = (|x_1|^p + |x_2|^p + ... + |x_n|^p)^(1/p)
```

Разные значения p дают «единичные шары» разной формы (множество всех точек на расстоянии 1 от начала координат):

```
p=1:    Diamond shape      (corners on axes)
p=2:    Circle/sphere      (the usual round ball)
p=3:    Superellipse       (rounded square)
p=inf:  Square/hypercube   (flat sides along axes)
```

> 🎒 **На пальцах.** «Единичный шар» — это ответ на вопрос «куда я могу дойти, потратив ровно 1 единицу пути». По прямой (p=2) — по кругу. По улицам (p=1) — получится ромб: по диагонали дальше не уйдёшь, приходится делать два хода вместо одного. Форма фигуры и есть портрет метрики.

### L-infinity Norm (Chebyshev distance)

Когда p стремится к бесконечности, норма Lp сходится к максимальной по модулю компоненте.

```
||x||_inf = max(|x_1|, |x_2|, ..., |x_n|)
```

Расстояние между двумя точками определяется единственным измерением, где они различаются сильнее всего. Все остальные игнорируются.

```
Point A = (1, 1)
Point B = (4, 5)

L-inf distance = max(|4-1|, |5-1|) = max(3, 4) = 4
```

Когда использовать L-бесконечность:
- Когда важно наихудшее отклонение по любому отдельному измерению
- Игровые доски (король в шахматах ходит по L-бесконечности: шаг в любую сторону стоит 1)
- Производственные допуски (каждый размер должен укладываться в норму)

> 🎒 **На пальцах.** Пример с королём точный: чтобы попасть с a1 на c3, король делает 2 хода, хотя сдвинулся и на 2 клетки вправо, и на 2 вверх. Диагональ бесплатна. Отсюда и формула: считается только большее из двух смещений.

### Cosine Similarity and Cosine Distance

Косинусная близость измеряет угол между двумя векторами, игнорируя их длины.

```
cos_sim(a, b) = (a . b) / (||a||_2 * ||b||_2)
```

Она меняется от -1 (противоположные направления) до +1 (то же направление). У перпендикулярных векторов косинусная близость равна 0.

Косинусное расстояние переводит её в расстояние: cosine_distance = 1 - cosine_similarity. Оно меняется от 0 (одинаковое направление) до 2 (противоположное).

```
a = (1, 0)    b = (1, 1)

cos_sim = (1*1 + 0*1) / (1 * sqrt(2)) = 1/sqrt(2) = 0.707
cos_dist = 1 - 0.707 = 0.293
```

Почему косинус царит в NLP и векторных представлениях: в тексте длина документа не должна влиять на похожесть. Документ про кошек, вдвое длиннее другого документа про кошек, всё равно должен считаться «похожим». Косинусная близость игнорирует длину и смотрит только на направление. Два документа с одинаковым распределением слов, но разной длины указывают в одну сторону и получают близость 1.0.

Когда использовать косинусную близость:
- Похожесть текстов (векторы TF-IDF, представления слов, представления предложений)
- Любая область, где длина — шум, а направление — сигнал
- Рекомендательные системы (векторы предпочтений пользователей)
- Поиск по представлениям (векторные базы почти всегда используют косинус или скалярное произведение)

> 🎒 **На пальцах.** Два человека идут в одну сторону: один прошёл километр, другой сто метров. Направление у них одинаковое, значит «похожи» — косинус равен 1. А расстояние между ними при этом огромное. Так и с текстами: короткая заметка и длинная статья на одну тему указывают в одну сторону, хотя по длине несравнимы.

### Dot Product Similarity vs Cosine Similarity

Скалярное произведение двух векторов:

```
a . b = a_1*b_1 + a_2*b_2 + ... + a_n*b_n
      = ||a|| * ||b|| * cos(angle)
```

Косинусная близость — это скалярное произведение, поделённое на обе длины. Когда оба вектора уже нормированы (длина = 1), скалярное произведение и косинусная близость совпадают.

```
If ||a|| = 1 and ||b|| = 1:
    a . b = cos(angle between a and b)
```

Чем они отличаются: скалярное произведение несёт информацию о длине. Вектор с большей длиной получает более высокую оценку. Это важно в некоторых системах поиска, где «популярные» объекты должны стоять выше. Длина работает неявным сигналом качества или важности.

```
a = (3, 0)    b = (1, 0)    c = (0, 1)

dot(a, b) = 3     dot(a, c) = 0
cos(a, b) = 1.0   cos(a, c) = 0.0

Both agree on direction, but dot product also reflects magnitude.
```

На практике:
- Косинусная близость — когда нужна чисто направленная похожесть
- Скалярное произведение — когда длина несёт осмысленную информацию
- Многие векторные базы (Pinecone, Weaviate, Qdrant) позволяют выбрать между ними
- Если ваши представления L2-нормированы, выбор не имеет значения

### Mahalanobis Distance

Евклидово расстояние считает все измерения равноправными. Но если признаки скоррелированы или имеют разные масштабы, L2 вводит в заблуждение.

Расстояние Махаланобиса учитывает ковариационную структуру данных.

```
d_M(x, y) = sqrt((x - y)^T * S^(-1) * (x - y))
```

где S — ковариационная матрица данных.

Интуитивно: расстояние Махаланобиса сначала декоррелирует и нормирует данные (отбеливание), затем считает L2 в этом преобразованном пространстве. Если S — единичная матрица (некоррелированные признаки с единичной дисперсией), расстояние Махаланобиса вырождается в евклидово.

```
Example: height and weight are correlated.
Someone 6'2" and 180 lbs is not unusual.
Someone 5'0" and 180 lbs is unusual.

Euclidean distance might say they are equally far from the mean.
Mahalanobis distance correctly identifies the second as an outlier
because it accounts for the height-weight correlation.
```

Когда использовать расстояние Махаланобиса:
- Поиск выбросов (точки с большим расстоянием Махаланобиса от среднего — выбросы)
- Классификация, когда признаки имеют разные масштабы и корреляции
- Когда данных достаточно для надёжной оценки ковариационной матрицы
- Контроль качества на производстве (многомерный мониторинг процессов)

> 🎒 **На пальцах.** По-русски пример такой: человек ростом 188 см и весом 82 кг — обычный. Человек ростом 152 см и весом 82 кг — необычный. Вес одинаковый, но во втором случае он не сочетается с ростом. Евклидово расстояние этого не заметит, Махаланобис заметит, потому что знает: рост и вес связаны.

### Jaccard Similarity (for sets)

Мера Жаккара измеряет пересечение двух множеств.

```
J(A, B) = |A intersect B| / |A union B|
```

Она меняется от 0 (нет общего) до 1 (одинаковые множества). Расстояние Жаккара = 1 - мера Жаккара.

```
A = {cat, dog, fish}
B = {cat, bird, fish, snake}

Intersection = {cat, fish}         size = 2
Union = {cat, dog, fish, bird, snake}  size = 5

Jaccard similarity = 2/5 = 0.4
Jaccard distance = 0.6
```

Когда использовать Жаккара:
- Сравнение наборов тегов, категорий или признаков
- Похожесть документов по наличию слов (а не по частоте)
- Поиск почти-дубликатов (MinHash приближает Жаккара)
- Сравнение бинарных векторов признаков (данные «есть/нет»)
- Оценка моделей сегментации (Intersection over Union — это и есть Жаккар)

> 🎒 **На пальцах.** Сравните два списка подписок на каналы. Общих каналов — 2, всего разных на двоих — 5. Значит вкусы совпадают на 2/5 = 40%. Ровно так вам и подбирают друзей и рекомендации: делят общее на всё вместе.

### Edit Distance (Levenshtein Distance)

Редакционное расстояние считает минимальное число посимвольных операций для превращения одной строки в другую. Операции: вставка, удаление, замена.

```
"kitten" -> "sitting"

kitten -> sitten  (substitute k -> s)
sitten -> sittin  (substitute e -> i)
sittin -> sitting (insert g)

Edit distance = 3
```

Вычисляется динамическим программированием. Заполняем матрицу, где элемент (i, j) — редакционное расстояние между первыми i символами строки A и первыми j символами строки B.

```
        ""  s  i  t  t  i  n  g
    ""   0  1  2  3  4  5  6  7
    k    1  1  2  3  4  5  6  7
    i    2  2  1  2  3  4  5  6
    t    3  3  2  1  2  3  4  5
    t    4  4  3  2  1  2  3  4
    e    5  5  4  3  2  2  3  4
    n    6  6  5  4  3  3  2  3
```

Когда использовать редакционное расстояние:
- Проверка и исправление орфографии
- Выравнивание последовательностей ДНК (с весами операций)
- Нечёткое сопоставление строк
- Дедупликация грязных текстовых данных

> 🎒 **На пальцах.** Именно так работает автозамена в телефоне. Вы написали «превет» — до слова «привет» одна замена буквы, расстояние 1. До слова «конверт» — замен куда больше. Телефон предлагает то, до чего ближе всего.

### KL Divergence (not a distance, but used like one)

KL divergence измеряет, насколько одно распределение вероятностей отличается от другого. Разбиралась в уроке 09, но её место и в этом обсуждении, потому что её используют как «расстояние», хотя она им не является.

```
D_KL(P || Q) = sum(p(x) * log(p(x) / q(x)))
```

Ключевое свойство: KL divergence НЕ симметрична.

```
D_KL(P || Q) != D_KL(Q || P)
```

Значит она не удовлетворяет базовому требованию метрики. Она также не удовлетворяет неравенству треугольника. Это дивергенция, а не расстояние.

Прямая KL (D_KL(P || Q)) «ищет среднее»: Q старается покрыть все моды P.
Обратная KL (D_KL(Q || P)) «ищет моду»: Q фокусируется на одной моде P.

Где встречается KL divergence:
- VAE (слагаемое KL в ELBO подталкивает латентное распределение к априорному)
- Дистилляция знаний (ученик старается повторить распределение учителя)
- RLHF (штраф KL удерживает дообученную модель близко к базовой)
- Методы policy gradient (ограничение обновлений политики)

### Wasserstein Distance (Earth Mover's Distance)

Расстояние Вассерштейна измеряет минимальную «работу», нужную для превращения одного распределения в другое. Думайте так: одно распределение — куча земли, другое — яма; сколько земли и как далеко надо перевезти?

```
W(P, Q) = inf over all transport plans gamma of E[d(x, y)]
```

Для одномерных распределений оно упрощается до интеграла модуля разности функций распределения:

```
W_1(P, Q) = integral |CDF_P(x) - CDF_Q(x)| dx
```

Почему Вассерштейн важен:
- Это настоящая метрика (симметрична, удовлетворяет неравенству треугольника)
- Она даёт градиенты даже когда распределения не перекрываются (KL divergence уходит в бесконечность)
- Это свойство сделало её центральной в Wasserstein GAN (WGAN), решивших проблему нестабильности исходных GAN

```
Distributions with no overlap:

P: [1, 0, 0, 0, 0]    Q: [0, 0, 0, 0, 1]

KL divergence: infinity (log of zero)
Wasserstein: 4 (move all mass 4 bins)

Wasserstein gives a meaningful gradient. KL does not.
```

Когда использовать Вассерштейна:
- Обучение GAN (WGAN, WGAN-GP)
- Сравнение распределений, которые могут не перекрываться
- Задачи оптимального транспорта
- Поиск изображений (сравнение цветовых гистограмм)

> 🎒 **На пальцах.** Смысл примера: два распределения вообще не пересекаются. KL говорит «бесконечно далеко» — и это бесполезный ответ, из него не понять, в какую сторону двигаться. Вассерштейн говорит «4 ящика» — и если стало 3, значит вы приблизились. Именно поэтому GAN на нём обучаются, а на KL ломались.

### Why Different Tasks Need Different Distances

| Task | Best distance | Why |
|------|--------------|-----|
| Похожесть текстов | Косинус | Длина — шум, направление — смысл |
| Сравнение пикселей изображений | L2 | Важны пространственные отношения, масштабы признаков сопоставимы |
| Разреженные многомерные признаки | L1 | Устойчиво, не раздувает редкие большие различия |
| Пересечение множеств (теги, категории) | Жаккар | Данные по природе множества, а не векторы |
| Сопоставление строк | Редакционное расстояние | Операции соответствуют человеческой правке |
| Поиск выбросов | Махаланобис | Учитывает корреляции и масштабы признаков |
| Сравнение распределений | KL divergence | Меряет информацию, теряемую при использовании Q вместо P |
| Обучение GAN | Вассерштейн | Даёт градиенты даже без перекрытия распределений |
| Представления (векторная база) | Косинус или скалярное произведение | Представления обучены кодировать смысл в направлении |
| Рекомендации | Скалярное произведение | Длина может кодировать популярность или уверенность |
| Последовательности ДНК | Взвешенное редакционное расстояние | Стоимость замены зависит от пары нуклеотидов |
| Контроль качества на производстве | L-бесконечность | Важно наихудшее отклонение по любому измерению |

### Connection to Loss Functions

Функции потерь — это функции расстояния, применённые к предсказаниям против целей.

```
Loss function       Distance it uses       Behavior
MSE                 L2 squared             Penalizes large errors heavily
MAE                 L1                     Penalizes all errors equally
Huber loss          L1 for large errors,   Best of both: robust to outliers,
                    L2 for small errors    smooth gradient near zero
Cross-entropy       KL divergence          Measures distribution mismatch
Hinge loss          max(0, margin - d)     Only penalizes below margin
Triplet loss        L2 (typically)         Pulls positives close, pushes
                                           negatives away
Contrastive loss    L2                     Similar pairs close, dissimilar
                                           pairs beyond margin
```

### Connection to Regularization

Регуляризация добавляет к функции потерь штраф по норме весов.

```
L1 regularization (Lasso):   loss + lambda * ||w||_1
  -> Sparse weights. Some weights become exactly zero.
  -> Automatic feature selection.
  -> Solution has corners (non-differentiable at zero).

L2 regularization (Ridge):   loss + lambda * ||w||_2^2
  -> Small weights. All weights shrink toward zero.
  -> No feature selection (nothing goes to exactly zero).
  -> Smooth solution everywhere.

Elastic Net:                  loss + lambda_1 * ||w||_1 + lambda_2 * ||w||_2^2
  -> Combines sparsity of L1 with stability of L2.
  -> Groups of correlated features are kept or dropped together.
```

Почему L1 даёт разреженность, а L2 нет: представьте область ограничений в двумерном пространстве весов. L1 — ромб, L2 — круг. Линии уровня функции потерь (эллипсы) с большой вероятностью коснутся ромба именно в углу, где один вес равен нулю. Круга они касаются в гладкой точке, где оба веса ненулевые.

> 🎒 **На пальцах.** Проще некуда: у ромба есть острые углы, и они лежат ровно на осях. Мячик, катящийся к ромбу, чаще всего упирается в угол — а угол означает «один вес обнулился». У круга углов нет, упереться некуда, поэтому нули и не получаются.

### Nearest Neighbor Search

Каждая функция расстояния порождает задачу поиска ближайших соседей: по точке-запросу найти ближайшие точки в наборе данных.

Точный поиск стоит O(n * d) на запрос при n точках и d измерениях. Для больших наборов это слишком медленно.

Алгоритмы приближённого поиска (ANN) меняют небольшую потерю точности на огромный выигрыш в скорости:

```
Algorithm         Approach                      Used by
KD-trees          Axis-aligned space partition   scikit-learn (low-dim)
Ball trees        Nested hyperspheres            scikit-learn (medium-dim)
LSH               Random hash projections        Near-duplicate detection
HNSW              Hierarchical navigable         FAISS, Qdrant, Weaviate
                  small-world graph
IVF               Inverted file index with       FAISS (billion-scale)
                  cluster-based search
Product quant.    Compress vectors, search       FAISS (memory-constrained)
                  in compressed space
```

HNSW (Hierarchical Navigable Small World) — доминирующий алгоритм в современных векторных базах. Он строит многослойный граф, где каждый узел связан со своими приближёнными ближайшими соседями. Поиск начинается на верхнем слое (разреженном, длинные прыжки) и спускается к нижнему (плотному, короткие шаги).

> 🎒 **На пальцах.** HNSW работает как поиск дома в чужом городе: сначала на самолёте до нужной страны, потом на поезде до города, потом пешком до улицы. Верхние слои — длинные прыжки, нижние — мелкие шаги. Куда быстрее, чем обходить каждый дом на планете подряд.

## Build It

### Step 1: All norm and distance functions

Полная реализация в `code/distances.py`. Каждая функция построена с нуля на базовой математике Python.

### Step 2: Same data, different distances, different neighbors

Демонстрация в `distances.py` создаёт набор данных, выбирает точку-запрос и показывает, как ближайший сосед меняется в зависимости от метрики. Точка, «ближайшая» по L1, может не быть ближайшей по L2 или косинусу.

### Step 3: Embedding similarity search

Код включает учебный поиск по представлениям, находящий самые похожие «документы» на запрос через косинусную близость против L2, и показывает, что ранжирования могут различаться.

## Use It

Самое частое практическое применение: поиск похожих объектов в векторной базе.

```python
import numpy as np

def cosine_similarity_matrix(X):
    norms = np.linalg.norm(X, axis=1, keepdims=True)
    norms = np.where(norms == 0, 1, norms)
    X_normalized = X / norms
    return X_normalized @ X_normalized.T

embeddings = np.random.randn(1000, 768)

sim_matrix = cosine_similarity_matrix(embeddings)

query_idx = 0
similarities = sim_matrix[query_idx]
top_k = np.argsort(similarities)[::-1][1:6]
print(f"Top 5 most similar to item 0: {top_k}")
print(f"Similarities: {similarities[top_k]}")
```

Когда вы вызываете `model.encode(text)` и ищете в векторной базе, происходит именно это. Модель представлений переводит текст в векторы. Векторная база считает косинусную близость (или скалярное произведение) между вашим запросом и каждым сохранённым вектором, используя ANN-алгоритмы, чтобы не проверять все подряд.

> 🎒 **На пальцах.** Заметьте срез `[1:6]`, а не `[0:5]`. Самый похожий на себя объект — он сам, близость 1.0. Его выбрасывают, иначе поиск похожих товаров всегда показывал бы тот же самый товар первым.

## Key Terms

| Term | What people say | What it actually means |
|------|----------------|----------------------|
| Norm | «Размер вектора» | Функция, переводящая вектор в неотрицательное число и удовлетворяющая неравенству треугольника, абсолютной однородности и нулю только для нулевого вектора |
| L1 norm | «Манхэттенское расстояние» | Сумма модулей компонент. Даёт разреженность при оптимизации. Устойчива к выбросам |
| L2 norm | «Евклидово расстояние» | Корень из суммы квадратов компонент. Расстояние по прямой в евклидовом пространстве |
| Lp norm | «Обобщённая норма» | Корень степени p из суммы p-х степеней модулей компонент. L1 и L2 — частные случаи |
| L-infinity norm | «Максимальная норма» или «расстояние Чебышёва» | Наибольшее по модулю значение компоненты. Предел Lp при p, стремящемся к бесконечности |
| Cosine similarity | «Угол между векторами» | Скалярное произведение, поделённое на обе длины. От -1 до +1. Игнорирует длину вектора |
| Cosine distance | «Единица минус косинусная близость» | Переводит косинусную близость в расстояние. От 0 до 2 |
| Dot product | «Ненормированный косинус» | Сумма покомпонентных произведений. Равна косинусной близости, умноженной на обе длины |
| Mahalanobis distance | «Расстояние с учётом корреляций» | L2-расстояние в пространстве, отбелённом (декоррелированном и нормированном) по ковариационной матрице данных |
| Jaccard similarity | «Пересечение множеств» | Размер пересечения, делённый на размер объединения. Для множеств, не для векторов |
| Edit distance | «Расстояние Левенштейна» | Минимум вставок, удалений и замен для превращения одной строки в другую |
| KL divergence | «Расстояние между распределениями» | Не настоящее расстояние (несимметрично). Меряет лишние биты при кодировании P через Q |
| Wasserstein distance | «Расстояние землекопа» | Минимальная работа по переносу массы из одного распределения в другое. Настоящая метрика |
| Approximate nearest neighbor | «ANN-поиск» | Алгоритмы (HNSW, LSH, IVF), находящие приближённо ближайшие точки намного быстрее точного перебора |
| HNSW | «Алгоритм векторных баз» | Hierarchical Navigable Small World. Многослойный граф для быстрого приближённого поиска соседей |
| L1 regularization | «Lasso» | Добавление L1-нормы весов к потерям. Загоняет веса в ноль (разреженность) |
| L2 regularization | «Ridge» или «weight decay» | Добавление квадрата L2-нормы весов к потерям. Ужимает веса к нулю без разреженности |
| Elastic Net | «L1 + L2» | Комбинация L1 и L2-регуляризации. Лучше справляется с группами скоррелированных признаков, чем каждая по отдельности |
